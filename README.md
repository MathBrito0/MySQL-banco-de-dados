## 🚀 Sobre o Projeto

Este espaço reúne scripts SQL, modelagem de dados, consultas (`SELECT`, `JOIN`, subqueries) e boas práticas para gerenciamento e manipulação de dados.

* Estruturação de tabelas e relacionamentos (Chaves Primárias e Estrangeiras).
* Consultas otimizadas e filtragem avançada de dados.
* Scripts focados em cenários práticos de negócios.
